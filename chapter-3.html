От перцептрона к MLP: как нейросеть учится

Один нейрон умеет проводить прямую. Скрытый слой превращает прямую в произвольную границу. Обратное распространение говорит, как подкрутить миллионы весов. Эта глава — фундамент, на котором стоит всё остальное, включая KAN.

Глава 3 из 9 ≈ 70 минут теория · демонстрации · код сложность: средняя

Вопрос не в том, может ли машина мыслить, а в том, может ли она учиться на своём опыте. По мотивам идей Алана Тьюринга и Фрэнка Розенблатта

Перед главой

Нужны глава 1 и матрицы из 2.1. Если слова «перцептрон» и «MLP» вам незнакомы — это нормально: начнём с одного нейрона и постепенно дойдём до обратного распространения. Код в конце — обязательная практика: сначала можно разобрать формулы, затем запустить пример.

Перцептрон: один нейрон и одна прямая

Искусственный нейрон — это взвешенная сумма входов плюс смещение, после которой применяется нелинейность. В исходном перцептроне Розенблатта нелинейность была ступенькой:

z = Σi wixi + b,    ŷ = 1, если z ≥ 0, иначе 0
Перцептрон. Один нейрон делит пространство входов гиперплоскостью w·x + b = 0.

В двумерном случае это просто прямая. Нейрон относит точку к классу 1, если она лежит по одну сторону прямой, и к классу 0 — если по другую. Обучение по Розенблатту подправляет веса только тогда, когда ответ неверен:

w ← w + η (y − ŷ) x,    b ← b + η (y − ŷ)
Правило перцептрона. Если ответ верен, ничего не меняется; если нет — веса сдвигаются в сторону правильного класса.

Для линейно разделимых данных этот алгоритм гарантированно сходится за конечное число шагов — это теорема о сходимости перцептрона. Но именно слово «линейно» и стало ловушкой.

Проблема XOR

Рассмотрим четыре точки в вершинах единичного квадрата. Класс 1 — точки (0,1) и (1,0), класс 0 — (0,0) и (1,1). Это функция «исключающее ИЛИ»: результат равен 1, только если входы разные.

x₁x₂y = XOR
000
011
101
110

Минский и Пейперт в 1969 году показали, что однослойный перцептрон не может вычислить XOR. Это ограничение стало одним из аргументов против нейросетей на десятилетия. Решение оказалось простым: добавить скрытый слой, который сам создаёт новые признаки.

Например, пусть скрытые нейроны вычисляют «ИЛИ» и «И»: h1 = step(x1 + x2 − 0.5), h2 = step(x1 + x2 − 1.5). Тогда y = step(h1 − h2 − 0.5) даёт ровно XOR: для (1,1) оба скрытых нейрона активны и вычитаются, для (1,0) и (0,1) активен только первый, для (0,0) — ни один.

Геометрическая интуиция

Скрытый слой переводит входы в новое пространство, где задача становится линейно разделимой. Глубина — это последовательность таких преобразований. Чем больше слоёв, тем более сложные «перегибы» пространства доступны сети.

Многослойный перцептрон

MLP (multi-layer perceptron) — это стопка полносвязных слоёв, каждый из которых заканчивается нелинейностью. Для двух скрытых слоёв и линейного выхода:

h1 = σ(W1x + b1),    h2 = σ(W2h1 + b2),    ŷ = W3h2 + b3
Прямой проход MLP. Каждый слой — линейное преобразование плюс нелинейность.

Ширина — число нейронов в слое, глубина — число слоёв. Число параметров слоя с nin входами и nout выходами равно ninnout + nout: матрица весов плюс смещения. Для сети 2 → 4 → 1 это (2·4 + 4) + (4·1 + 1) = 17 параметров.

Зачем нужна нелинейность

Если убрать σ, композиция линейных слоёв останется линейной: W2(W1x) = (W2W1)x. Сеть любой глубины схлопнется в одно линейное преобразование и не сможет выучить даже XOR. Нелинейность — не украшение, а источник выразительности.

Функции активации

Исторически использовали сигмоиду и гиперболический тангенс, затем пришли ReLU и его гладкие варианты. У каждой — свой профиль градиента.

Почему в KAN выбрана именно SiLU? Она гладкая, неограниченная сверху и хорошо ведёт себя при обучении. В формуле ребра KAN она играет роль «базовой линии», к которой добавляется сплайн: φ(x) = wb·SiLU(x) + spline(x). Это даёт модели и гладкий глобальный тренд, и локальную гибкость. Обратное распространение ошибки

Идея без формул

Модель ошиблась. Мы передаём эту ошибку назад по слоям и на каждом шаге умножаем на то, насколько сильно слой влиял на результат. Получаются градиенты — направления, в которых нужно подкрутить параметры. Формулы ниже — просто аккуратная запись этого процесса.

Теперь у нас есть сеть, но нет способа узнать, как менять её параметры. Обратное распространение — это правило цепочки, применённое к графу вычислений. Разберём его на минимальной сети x → h → ŷ с MSE.

z1 = W1x + b1,   h = σ(z1),   z2 = W2h + b2,   L = ½(ŷ − y)2
Сеть из одного скрытого слоя. Выход линейный, поэтому z₂ = ŷ.

Начнём с выхода. Производная потери по ŷ равна ошибке, а поскольку выход линейный, это же число является «сигналом ошибки» на выходном слое:

δ2 = ∂L∂z2 = ŷ − y
Ошибка выхода. Положительная, если модель завысила ответ.

Градиенты выходного слоя получаются умножением ошибки на вход слоя:

∂L∂W2 = δ2 hT,    ∂L∂b2 = δ2
Градиенты выходного слоя. Форма W₂ сохраняется: внешнее произведение векторов.

Чтобы передать ошибку назад, умножаем её на транспонированную матрицу весов и на производную активации скрытого слоя:

δ1 = ( W2T δ2 ) ⊙ σ′(z1)
Ошибка скрытого слоя. ⊙ — поэлементное умножение.

И наконец — градиенты первого слоя:

∂L∂W1 = δ1 xT,    ∂L∂b1 = δ1
Градиенты первого слоя. Тот же шаблон: сигнал ошибки × вход слоя.

Вся процедура состоит из двух проходов. Прямой сохраняет промежуточные значения (z1, h, ŷ). Обратный идёт от выхода к входу и на каждом шаге использует уже посчитанный сигнал ошибки. Именно повторное использование δ делает backprop эффективным: стоимость обратного прохода сравнима со стоимостью прямого, независимо от числа параметров.

backprop_pseudocode.py — два прохода 
# X: (B, d), y: (B, 1) — батч; W1: (m, d), W2: (1, m)
z1 = X @ W1.T + b1          # (B, m)
h = sigmoid(z1)             # (B, m)
y_hat = h @ W2.T + b2       # (B, 1)
loss = ((y_hat - y) ** 2).mean()

# обратный проход
d2 = 2.0 * (y_hat - y) / B            # (B, 1)
dW2 = d2.T @ h                        # (1, m)
db2 = d2.sum(axis=0)                  # (1,)
d1 = (d2 @ W2) * sigmoid_prime(z1)    # (B, m)
dW1 = d1.T @ X                        # (m, d)
db1 = d1.sum(axis=0)                  # (m,)

# шаг оптимизатора — уже отдельная операция
W1 -= lr * dW1
W2 -= lr * dW2
b1 -= lr * db1
b2 -= lr * db2

Терминологическая тонкость

Backpropagation — это не «алгоритм обучения», а способ вычислить градиенты. Обучение делает оптимизатор: SGD, momentum, Adam. Разделение важно: можно поменять оптимизатор, не меняя ни строчки в обратном проходе.

Как проверить градиенты

Если реализуете слой вручную, сравните аналитический градиент с конечной разностью:

∂L∂θ ≈ L(θ + ε) − L(θ − ε)2ε,    ε ≈ 10−5
Проверка градиента. Относительная ошибка порядка 10−6 говорит, что всё верно.

Это медленно и делается на маленьких тензорах, но экономит часы отладки. В главе 5 мы применим ту же идею к KAN: сплайны дают простые аналитические производные, и их легко проверить.

Обучение и обобщение

Мы умеем считать градиенты. Осталось собрать цикл обучения и понять, когда ему можно верить. Минимальный цикл выглядит так:

train_loop.py — скелет обучения 
for epoch in range(n_epochs):
    model.train()
    for xb, yb in train_loader:
        pred = model(xb)
        loss = loss_fn(pred, yb)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    model.eval()
    with torch.no_grad():
        val_loss = evaluate(model, val_loader)
    print(epoch, val_loss)

Ключевое различие — обучающая и тестовая выборки. На обучении мы минимизируем потери; на тесте проверяем, выучила ли модель закономерность или просто запомнила ответы. Если ошибка на обучении падает, а на тесте растёт — это переобучение. Если обе высоки — недообучение.

Это проявление компромисса смещения и разброса: слишком простая модель систематически ошибается (большое смещение), слишком сложная — сильно зависит от конкретной выборки (большой разброс). Регуляризация сдвигает баланс в сторону устойчивости.

Инициализация и устойчивость градиентов

Если веса слишком большие, активации и градиенты растут от слоя к слою и «взрываются»; если слишком маленькие — «затухают». Поэтому используют масштабированную инициализацию. Для Xavier (tanh, sigmoid) дисперсия пропорциональна 2/(nin + nout), для He (ReLU) — 2/nin.

Дополнительно помогают нормализация слоёв (BatchNorm, LayerNorm), residual-связи и аккуратный выбор активации. Всё это — способы удержать сигнал в разумном диапазоне на всей глубине сети.

Порядок действий

Начинайте с маленькой модели и маленького батча. Убедитесь, что она переобучает несколько примеров. Затем добавляйте ёмкость и регуляризацию. Так вы всегда понимаете, что именно изменило результат, а не гадаете по одной красивой цифре.

Теорема об универсальной аппроксимации

Естественный вопрос: достаточно ли одного скрытого слоя? Теорема Цыбенко–Хорника отвечает утвердительно — в теоретическом смысле. Для любой непрерывной функции на компактном множестве и любого ε > 0 найдётся однослойная сеть с сигмоидными активациями, которая приближает её равномерно с ошибкой меньше ε:

supx∈K | f(x) − fMLP(x) | < ε
Универсальная аппроксимация. Существование сети нужной ширины, но не рецепт её обучения.

Интуиция простая: каждый нейрон скрытого слоя создаёт «ступеньку» или «горб», а выходной слой складывает их с нужными весами. Чем больше нейронов, тем мельче сетка, которой можно приблизить функцию.

Чего теорема не обещает

Она не говорит, что ширина будет разумной: для точности ε в d измерениях может потребоваться экспоненциально много нейронов. Она не говорит, что градиентный спуск найдёт эти веса. И не говорит, что сеть будет интерпретируемой. Универсальность — свойство класса функций, а не гарантия успеха обучения.

У KAN есть свой аналог: теорема Колмогорова–Арнольда даёт точное представление непрерывной функции через одномерные функции и сложение. Но и здесь есть оговорка: внутренние функции в теореме могут быть негладкими и зависеть от функции сложным образом. Практический KAN заменяет их сплайнами и добавляет глубину, получая другой inductive bias — не «лучше вообще», а иначе.

Минимальный MLP на PyTorch

Соберём всё вместе на задаче XOR. Сеть 2 → 8 → 1 с tanh и сигмоидой обучается за пару секунд даже на слабом ноутбуке.

xor_mlp.py — запускается на CPU 
import torch
from torch import nn

X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = torch.tensor([[0.], [1.], [1.], [0.]])

model = nn.Sequential(
    nn.Linear(2, 8),
    nn.Tanh(),
    nn.Linear(8, 1),
    nn.Sigmoid(),
)

optimizer = torch.optim.Adam(model.parameters(), lr=0.05)
loss_fn = nn.MSELoss()

for epoch in range(2001):
    pred = model(X)
    loss = loss_fn(pred, y)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if epoch % 500 == 0:
        print(f"epoch {epoch:4d}  loss {loss.item():.5f}")

with torch.no_grad():
    print(model(X).round().flatten().tolist())  # [0.0, 1.0, 1.0, 0.0]

Обратите внимание: мы не программируем XOR вручную. Мы задаём архитектуру, функцию потерь и оптимизатор, а веса находит градиентный спуск. Это и есть обучение в его простейшем виде.

Мост к KAN

В KAN на месте nn.Linear стоит слой, который для каждого ребра хранит сплайн. Всё остальное — данные, потери, оптимизатор, цикл обучения — остаётся почти тем же. Понимая MLP, вы уже понимаете 90% инфраструктуры KAN.

Ответы и комментарии
  1. Классы XOR лежат на диагоналях квадрата, поэтому любая прямая оставит одну точку не с той стороны. Нужна как минимум одна «складка» пространства — скрытый слой.
  2. (3·5 + 5) + (5·5 + 5) + (5·1 + 1) = 20 + 30 + 6 = 56.
  3. Ошибка проходит через нелинейность, поэтому умножается на её производную: δ1 = (W2Tδ2) ⊙ σ′(z1). Без этого множителя мы бы игнорировали, насколько чувствителен выход к изменению z1.
  4. Без zero_grad() градиенты накапливаются: каждый шаг использует сумму всех предыдущих. Обучение станет неустойчивым. Двойной backward без обнуления даст удвоенный градиент.
  5. Валидация нужна для выбора гиперпараметров и ранней остановки, тест — только для финальной честной оценки. Если подбирать по тесту, он «протекает» в модель, и оценка перестаёт быть независимой.
  6. MLP: (2·8 + 8) + (8·1 + 1) = 24 + 9 = 33. KAN: на ребро G + k + 1 = 9 параметров; (2·8·9 + 8) + (8·1·9 + 1) = 152 + 73 = 225. Отношение ≈ 6.8×. Именно поэтому KAN выгоден, когда малая сеть уже достаточно выразительна, а не когда нужны миллионы параметров.
  7. Любую непрерывную функцию на компактном множестве можно приблизить однослойной сетью с любой наперёд заданной точностью. Ограничения: нужная ширина может быть экспоненциально большой, а факт существования весов не гарантирует, что оптимизатор их найдёт.

Итоги главы

  • Один нейрон — линейная граница. XOR показал, что без скрытых слоёв этого недостаточно.
  • MLP — композиция линейных слоёв и нелинейностей; именно нелинейность делает глубокую сеть выразительной.
  • Обратное распространение — это правило цепочки на графе вычислений: ошибка выхода последовательно умножается на локальные производные.
  • Обобщение важнее ошибки на обучении: нужны валидация, регуляризация и контроль переобучения.
  • Универсальная аппроксимация объясняет, почему MLP в принципе может выучить всё, но не объясняет, почему это будет дёшево и интерпретируемо.
