Нулевой модуль: Python, математика и словарь

Если вы никогда не программировали и не знаете слов MLP, LLM и «претрейн» — начните здесь. Этот модуль не заменяет учебник по Python, но даёт минимум, чтобы читать книгу и запускать примеры.

Модуль 0 · для старта с нуля ≈ 45 минут Python · обозначения · глоссарий сложность: новичок

Не обязательно знать всё заранее. Достаточно понимать, где искать. Практическое правило этой книги

Как запустить Python

Для чтения книги Python не обязателен. Для практики — нужен. Проверьте, установлен ли он:

терминал 
$ python3 --version
Python 3.12.3

Если команда не найдена, установите Python 3.10+ с официального сайта или через пакетный менеджер системы. Дальше создайте отдельное окружение, чтобы не засорять системный Python:

терминал — виртуальное окружение 
$ cd /home/alexey/Projects/KANBook
$ python3 -m venv .venv
$ source .venv/bin/activate          # Windows: .venv\Scripts\activate
$ python --version

Запуск скрипта — это просто вызов файла: python3 code/kan_demo_pure.py. Строка python3 означает «интерпретатор Python версии 3», а путь — файл, который нужно выполнить. Ошибка в терминале — нормально: читайте последнюю строку, там обычно написано, что не так.

КомандаЧто делает
python3 file.pyЗапустить файл
python3Открыть интерактивную консоль (REPL)
pip install packageУстановить библиотеку в окружение
Ctrl+CПрервать долгую команду
Ctrl+D или exit()Выйти из Python

Нужен ли PyTorch?

В части I есть примеры на PyTorch, но основной путь в части II — чистый Python и браузер. PyTorch понадобится, если вы захотите обучать глубокие KAN на своих данных. Для первых шагов достаточно стандартной библиотеки.

Python за двадцать минут

Программа — это последовательность инструкций. Переменная — имя, под которым хранится значение. Вот минимальный набор конструкций, которых хватит для книги.

basics.py — переменные и числа 
x = 2.5              # число
name = "Iris"        # строка
is_ready = True      # логическое значение

y = x * 2 + 1
print(y)             # 6.0
print(f"x = {x}, y = {y}")

Списки хранят последовательность, словари — пары «ключ → значение». Индексация в Python начинается с нуля.

collections.py — списки и словари 
features = [5.1, 3.5, 1.4, 0.2]
print(features[0])        # 5.1
print(len(features))      # 4

sample = {"species": "setosa", "petal_width": 0.2}
print(sample["species"])  # setosa

for value in features:
    print(value * 2)

Функция — именованный блок кода с аргументами и возвращаемым значением. Именно так в книге оформлены базис, прямой проход и потери.

functions.py — функция и цикл 
def normalize(value, lo, hi):
    return -1 + 2 * (value - lo) / (hi - lo)

for value in [4.3, 5.1, 7.9]:
    print(normalize(value, 4.3, 7.9))

Импорт подключает модуль. Например, import math даёт math.sin, math.exp и math.sqrt. Файлы читают через open(...), а ошибки ловят конструкцией try/except.

files.py — чтение CSV 
import csv

with open("code/data/iris.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["species"], row["petal_width"])
        break

Как учиться программированию

Набирайте код руками, меняйте числа, ломайте и читайте ошибки. Одна ошибка, которую вы исправили сами, стоит десяти прочитанных примеров. Не бойтесь временно удалить строку и посмотреть, что изменится.

Как читать математические записи

Формулы в книге — не экзамен. Это сжатая запись того, что делает код. Достаточно знать несколько символов.

ЗаписьЧитается какСмысл
Σi=1N xi«сумма xi по i от 1 до N»Сложить все значения
xi«x с индексом i»Элемент номер i
x2«x в квадрате»Умножить x на себя
f(x)«f от x»Функция применяется к x
θ«тета»Все параметры модели
∂L/∂w«частная производная L по w»Как меняется L при изменении w
∇L«градиент L»Вектор всех производных
arg minθ«θ, при котором минимум»Найти лучшие параметры
∈«принадлежит»Элемент множества
≈«примерно равно»Приближение

Вектор — список чисел, матрица — таблица чисел. Запись W ∈ ℝm×d означает «матрица W с m строками и d столбцами». Произведение Wx — это применение линейного преобразования к вектору.

Полезная привычка

Читая формулу, проговаривайте её словами и проверяйте на маленьком примере. Например, возьмите два числа и посмотрите, что даёт сумма. Если формула не пугает на двойке, она не страшна и на тысяче.

Словарь: ML, MLP, LLM и KAN

Эти слова встретятся в книге постоянно. Определения короткие; подробности будут в главах.

ТерминПростыми словами
Машинное обучение (ML)Программа учится на данных, а не работает по жёстко прописанным правилам
НейросетьФункция с настраиваемыми параметрами, собранная из слоёв
MLPМногослойный перцептрон: полносвязная нейросеть, где нелинейность стоит в узлах
СлойОдин шаг преобразования входа в выход
ВесЧисло, на которое умножается вход
Смещение (bias)Постоянная добавка к выходу
АктивацияНелинейная функция: ReLU, SiLU, tanh и т. п.
Функция потерьЧисло, показывающее, насколько модель ошиблась
ГрадиентНаправление и скорость роста потерь; учимся идти против него
ЭпохаОдин полный проход по обучающим данным
БатчПорция примеров для одного шага обучения
ПереобучениеМодель запомнила тренировку и плохо работает на новых данных
KANСеть, где обучаемые функции стоят на рёбрах, а узлы только суммируют
СплайнКусочно-полиномиальная функция; в KAN задаёт форму ребра
LLMБольшая языковая модель: трансформер, предсказывающий следующий токен
ТокенКусочек текста (слово, часть слова, символ), превращённый в число
ТрансформерАрхитектура с self-attention и MLP-блоками; основа современных LLM
ПретрейнПервое обучение на большом корпусе для общих представлений
ДообучениеАдаптация предобученной модели к конкретной задаче
ИнференсПрименение обученной модели к новым данным
РазвёртываниеЗапуск модели в виде страницы, API или сервиса для пользователей

Если запомнить только одно

MLP учит числа на рёбрах, KAN — функции на рёбрах. LLM — это большая сеть, которая предсказывает следующий токен. Всё остальное — уточнения.

Ориентир по времени: модуль 0 — 45 минут, главы 1–5 — около 5 часов, главы 6–9 — ещё около 4 часов, практика — от одного вечера. Не гонитесь за скоростью: лучше пройти три главы и запустить три примера, чем прочитать девять и не запустить ни одного.

Как читать код в книге

Сначала запустите как есть. Потом измените один параметр (например, число шагов или G). Потом сломайте что-нибудь специально и прочитайте ошибку. Так появляется понимание, которого не даёт пассивное чтение.

Упражнения

  1. Запустите python3 code/kan_demo_pure.py. Что напечатала программа в последней строке?
  2. Объясните своими словами, что означает запись Σi=13 xi.
  3. Чем MLP отличается от KAN в одном предложении?
  4. Что такое токен и зачем он нужен LLM?
  5. Зачем нужны train, validation и test, если можно просто обучить модель?
Ответы и комментарии
  1. Строка с коэффициентами сплайна — например, +0.4163, -0.0116, .... До неё программа печатает MSE до и после обучения.
  2. Сумма трёх чисел: x1 + x2 + x3.
  3. В MLP обучаются числа-веса, а нелинейность фиксирована в узлах; в KAN обучаются функции на рёбрах, а узлы только суммируют.
  4. Токен — кусочек текста, превращённый в число. LLM предсказывает следующий токен, поэтому ей нужен дискретный алфавит.
  5. Train — учиться, validation — выбирать настройки, test — один раз честно оценить. Иначе модель можно подогнать под все данные и получить завышенную оценку.

Итоги модуля

  • Python запускается командой python3 file.py; для практики достаточно базовых типов, циклов и функций.
  • Математические записи — это сжатый код; Σ, индексы и производные читаются словами.
  • MLP учит числа на рёбрах, KAN — функции; LLM предсказывает следующий токен.
  • У книги один маршрут: идите по порядку и не пропускайте практику. Знакомое будет повторением — это нормально и полезно.
