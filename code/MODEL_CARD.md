# Модель-карточка: Iris KAN 4 → 3

## Назначение

Учебная модель классифицирует три вида ириса по четырём измерениям цветка.
Создана как сквозной пример книги KANBook: данные → обучение → оценка →
экспорт → браузерное демо → HTTP-сервис.

## Архитектура

- Один слой KAN: 4 входа → 3 логита.
- Каждое ребро: B-сплайн степени 3 на сетке G = 5 (8 коэффициентов) + SiLU.
- Параметров: 3 · 4 · (8 + 1) + 3 = 111.
- После логитов — softmax, обучение по кросс-энтропии.

## Данные

- Iris: 150 примеров, 4 числовых признака, 3 сбалансированных класса.
- Обучение: 120 примеров (стратифицированно), отложено 30.
- Нормализация min-max в [−1, 1]; min/max считаются только по train.
- Источник: классический публичный набор Iris.

## Метрики

| Метрика | Значение |
| --- | --- |
| 5-фолдовая CV (1200 шагов) | 95.3% ± 2.7% |
| Отложенные 30 примеров | 30/30 на данном split |
| Кросс-энтропия на тесте | ≈ 0.0056 |
| Размер весов | ≈ 4.3 КБ JSON |

30/30 — маленькая выборка; основная оценка обобщения — кросс-валидация.
Другой split или seed может дать 28/30 или 29/30.

## Входы и выходы

Вход: четыре числа в сантиметрах в диапазонах:

- sepal_length: 4.3–7.9
- sepal_width: 2.0–4.4
- petal_length: 1.0–6.9
- petal_width: 0.1–2.5

Выход: вероятности трёх классов (`setosa`, `versicolor`, `virginica`) и
наиболее вероятный класс.

Входы вне диапазона отклоняются: KAN не умеет надёжно экстраполировать.

## Предназначенное использование

- Демонстрация работы KAN и полного ML-цикла.
- Обучение и эксперименты на публичном наборе.
- Пример API и статического демо.

## Вне области применения

- Ботаническая идентификация реальных растений.
- Медицинские, юридические, финансовые или кадровые решения.
- Данные других видов, другие единицы измерения, пропуски.
- Замена эксперта или сколько-нибудь ответственные выводы.

## Ограничения и риски

- Маленький и простой набор; высокая accuracy не означает «понимание».
- Модель может быть переуверена: на типичных примерах вероятность близка к 1.
- Нет проверки на сдвиг данных и на новых поставщиков измерений.
- Нет калибровки вероятностей и доверительных интервалов.

## Воспроизведение

```bash
python3 code/iris_kan_pure.py --cv --cv-epochs 1200
python3 code/iris_kan_pure.py --export --epochs 3000
python3 code/test_predict.py
python3 code/serve_pure.py
```

## Артефакты

- `code/iris_model.json` — веса, нормализация, метрики.
- `assets/iris_model.js` — те же веса для браузера.
- `assets/demo-iris.js` — инференс на JavaScript.
- `code/serve_pure.py` — HTTP API.
- `demo.html` — интерфейс.

## Лицензия и происхождение

Код — учебный материал KANBook. Набор Iris — классический публичный датасет.
Модель не является медицинским изделием и не сертифицирована.
